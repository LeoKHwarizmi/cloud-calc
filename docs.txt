# 🟦 **1. Project Overview**
**cloud‑calc** is a multi‑user, terminal‑based SaaS calculator service.  
Users connect via **TCP**, authenticate, and access:

- A calculator REPL  
- Usage tracking (CPU, RAM, calculations)  
- Calculation history  
- Account info  

Admins have full CRUD access to users and system monitoring.

The project is designed to be:

- Minimal  
- Scalable  
- Easy to extend  
- Free of unnecessary dependencies  
- Production‑ready on Fly.io  

---

# 🟩 **2. Architecture Summary**

### ✔ **One VM for the Rust app**
- Runs the TCP server  
- Handles sessions  
- Executes calculations  
- Tracks usage  
- Communicates with PostgreSQL  

### ✔ **One VM for PostgreSQL (Fly.io managed)**
- Stores users  
- Stores history  
- Stores usage  
- Stores roles  
- Stores billing data  

### ✔ **Protocol: TCP**
- Perfect for REPL  
- Low overhead  
- Real‑time interaction  
- No HTTP complexity  

### ✔ **Async runtime: Tokio**
- Handles thousands of concurrent sessions  
- Lightweight and efficient

# 🟧 **3. Folder Structure (Final)**

```
cloud-calc/
 ├── Cargo.toml
 └── src/
      ├── main.rs            # entry point
      ├── server.rs          # TCP listener
      ├── session.rs         # session state machine
      ├── menu.rs            # UI menus (welcome, user panel, admin panel)
      ├── auth.rs            # login/register/password hashing
      ├── db.rs              # SQLx queries
      ├── calculator.rs      # math evaluation (meval)
      ├── admin.rs           # admin commands (CRUD, usage, history)
      ├── user.rs            # CPU/RAM tracking + time formatting + helpers
      └── utils.rs           # optional helpers
```

This is a **flat, clean, scalable** Rust project layout.
